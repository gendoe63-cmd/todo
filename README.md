# Tiny To-Do (bug-hunt practice repo)

A very small to-do app built with plain HTML, CSS and JavaScript. No build step, no dependencies.

## Run it
Open `index.html` in your browser (double-click it, or use the VS Code "Live Server" extension).

## Run the tests (optional)
```
npm test
```
Requires Node.js 18 or newer.

## Project layout
| File | What it does |
|---|---|
| `index.html` | Page structure |
| `style.css` | Styling |
| `todo-logic.js` | Pure functions: add, complete, count |
| `app.js` | Button clicks and drawing the list on the page |
| `test/todo.test.js` | Unit tests for the logic |
